# Obsidian Custom Theme

This is a very personalized theme to be used for me in Obsidian.

## Requirements

The theme references these fonts but does not embed them; install them on the system:

- [Nunito](https://fonts.google.com/specimen/Nunito) — interface and reading view
- [FiraCode Nerd Font](https://www.nerdfonts.com/font-downloads) — editor and code

Missing fonts fall back to Roboto / Roboto Mono, then Obsidian's defaults.

## Install locally

```sh
OBSIDIAN__VAULT_PATH=/path/to/vault npm run build
```

Then enable **GAJAGUAR** in *Settings › Appearance › Themes*.
